# v1.6 — Report Builder + Export + Printing Engine

Implemented:
- Custom report builder for Sales, Purchase, Inventory Valuation and Account Ledger.
- Column selection, text filtering, date range, sorting and grouping.
- Persistent saved report definitions in SQLite, scoped to the active company and creator.
- Granular permissions: `reports.view` and `reports.builder.manage`.
- Audit records for saved/deleted report definitions.
- CSV export with UTF-8 BOM for Persian Excel compatibility.
- Excel-compatible `.xls` HTML export.
- Print Preview workflow. The browser print dialog can save the rendered report as PDF.
- RTL print layout.
- Empty, loading and error states.

Validation note:
- Static contract and archive tests were executed in three independent passes.
- Native Tauri/Rust build could not be executed in this environment because Cargo/Rust is unavailable.
