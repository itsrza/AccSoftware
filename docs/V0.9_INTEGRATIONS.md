# v0.9 — Plugin / DLL / API Integration

## Plugin Runtime
- Registry in SQLite.
- Explicit enable/disable.
- Manifest validation.
- Declared permission list.
- Native worker runs outside the renderer.
- Worker receives JSON over stdin and returns JSON/text over stdout.
- 15 second execution timeout.
- Worker stdout is capped at 1 MB.
- Plugin files are stored under the application data `plugins` directory.

## Native / DLL Boundary
React never loads or executes DLLs. A native integration must use an isolated worker/adapter executable. The worker can load the vendor DLL and expose a narrow JSON protocol. A worker crash does not terminate the renderer process.

## API Runtime
- API profiles are stored per company.
- HTTP/HTTPS only.
- Base host must be in the allowlist.
- Destination host is checked again for every request.
- Sensitive headers are blocked from caller input.
- API secrets are stored with the operating-system credential store through `keyring`; they are not stored in SQLite.
- Supported auth: none, API key, Bearer, Basic.
- Timeout is bounded to 1–120 seconds.
- Response body is capped at 1 MB.

## Security
- Backend permission checks are mandatory.
- `native.execute` is required for native workers.
- `plugins.manage` is required for installation and state changes.
- `integrations.execute` is required for API calls.
- Every registration/state change is audited.
