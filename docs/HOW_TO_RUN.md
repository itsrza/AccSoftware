# راهنمای دیدن نرم‌افزار

سه راه برای دیدن نسخه‌ی فعلی وجود دارد، از ساده به کامل.

---

## راه ۱ — یک فایل، فقط دابل‌کلیک (ساده‌ترین)

بدون نصب هیچ نرم‌افزاری. مناسب برای وقتی می‌خواهید فقط **ظاهر و چیدمان** را ببینید
و بازخورد بدهید.

1. این آدرس را باز کنید:
   `https://github.com/itsrza/AccSoftware/blob/arena/01a0242f-accsoftware/docs/preview/index.html`
2. دکمه‌ی **Download raw file** (آیکون دانلود، بالای سمت راست فایل) را بزنید.
3. فایل دانلودشده را **دابل‌کلیک** کنید تا در مرورگر باز شود.

همین. کل برنامه در یک فایل است.

> ⚠️ **مهم:** در این حالت موتور مالی (Rust) اجرا نمی‌شود و داده‌ها شبیه‌سازی‌شده‌اند.
> بنر زرد بالای صفحه همین را یادآوری می‌کند. این فایل فقط برای بازبینی طراحی است،
> نه برای کار واقعی.

### اگر می‌خواهید روی گیت‌هاب و بدون دانلود ببینید
در مخزن به **Settings ← Pages** بروید و منبع را روی شاخه‌ی
`arena/01a0242f-accsoftware` و پوشه‌ی `/docs` تنظیم کنید. بعد از چند دقیقه از این
آدرس در دسترس است:

```
https://itsrza.github.io/AccSoftware/preview/
```

## راه ۲ — اجرای محلی رابط کاربری (برای دیدن تغییرات لحظه‌ای)

نیاز: **Node.js نسخه ۲۲ یا بالاتر** ([nodejs.org](https://nodejs.org))

```bash
git clone https://github.com/itsrza/AccSoftware.git
cd AccSoftware
git checkout arena/01a0242f-accsoftware
cd apps/desktop-ui
npm ci
npm run dev
```

سپس آدرس `http://localhost:5173` را در مرورگر باز کنید.

مزیت این روش: هر تغییری که من در کد می‌دهم، با یک `git pull` بلافاصله می‌بینید.
باز هم موتور مالی اجرا نمی‌شود (همان شبیه‌ساز طراحی فعال است).

## راه ۳ — برنامه‌ی واقعی دسکتاپ (کامل و با موتور مالی)

این تنها حالتی است که **نرم‌افزار واقعی** با پایگاه داده‌ی SQLite و موتور
حسابداری Rust اجرا می‌شود.

### پیش‌نیازها (ویندوز)
1. **Node.js 22+** — [nodejs.org](https://nodejs.org)
2. **Rust** — [rustup.rs](https://rustup.rs)
3. **Visual Studio Build Tools** با بسته‌ی «Desktop development with C++»
   — [aka.ms/vs/17/release/vs_BuildTools.exe](https://aka.ms/vs/17/release/vs_BuildTools.exe)
4. **WebView2** (روی ویندوز ۱۱ از قبل نصب است)

### اجرا
```bash
git clone https://github.com/itsrza/AccSoftware.git
cd AccSoftware
git checkout arena/01a0242f-accsoftware
cd apps/desktop-ui
npm ci
npm run tauri dev
```

اولین اجرا حدود ۵ تا ۱۵ دقیقه طول می‌کشد (کامپایل Rust). دفعات بعد چند ثانیه است.

### ساخت فایل نصبی
```bash
npm run tauri build
```
خروجی در `target/release/bundle/` ساخته می‌شود.

> برای دیدن داده‌ی نمونه، فایل `apps/desktop-ui/.env` بسازید و این خط را در آن
> بگذارید: `VITE_DEMO_MODE=true`
