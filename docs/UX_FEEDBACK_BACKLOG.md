## اصلاحات پس از بازخورد دوم (عرض بدنه)

| مشکل | ریشه | راه‌حل |
|---|---|---|
| فاصله‌ی خالی بزرگ کنار سایدبار | CSS قدیمی سایدبار را `position: fixed` می‌کرد و هم‌زمان به `main` هم `margin-right` می‌داد؛ فاصله دو بار اعمال می‌شد | ۴۷ قاعده‌ی چیدمان قدیمی حذف شد؛ چیدمان فقط با Grid در `theme.css` |
| اسکرول افقی و عرض ثابت | `body { min-width: 1100px }` | حذف شد |
| متن‌های ناخوانا در تم تیره | ۲۳ قاعده‌ی `.dark` قدیمی متغیرها را وارونه می‌کردند (`--bg: var(--text)`) | همه حذف شد؛ تم تیره فقط با توکن‌های `theme.css` |
| رنگ‌های ثابت مقاوم در برابر تم | ۱۷۵ رنگ hex ثابت در CSS | با متغیرهای تم جایگزین شد |

### افزوده‌های همین پاس
- `useSort`: مرتب‌سازی جدول با کلیک روی سربرگ (صعودی/نزولی) بدون فشار به پایگاه داده.
- ستون بدهکار/بستانکار با رنگ قرمز/سبز و فیلتر سه‌حالته در صفحه‌ی اشخاص.
- ترجمه‌ی کامل وضعیت‌های چک (۱۷ وضعیت).
- صفحه‌ی «در دست ساخت» با ذکر مرجع اسکرین‌شات و فاز، به‌جای صفحه‌ی خالی یا اشتباه.
