# چندزبانی (i18n) — فارسی · English · العربية

این سند می‌گوید زبان در این برنامه چطور کار می‌کند، چه چیزی ترجمه شده و
افزودن ترجمه‌ی تازه دقیقاً چه مراحلی دارد.

## ۱. تصمیم‌های پایه

| موضوع | تصمیم | چرا |
| --- | --- | --- |
| مرجع کلیدها | دیکشنری **فارسی** (`lib/i18n/fa.ts`) | نوع `TranslationKey` از شکل همین شیء ساخته می‌شود؛ کلید بدون معادل انگلیسی/عربی خطای کامپایل می‌دهد، نه متن جامانده در چشم کاربر |
| جهت صفحه | fa/ar راست‌به‌چپ، en چپ‌به‌راست، روی `<html dir>` | همه‌ی کلاس‌های منطقی تِیلویند (`ps-`, `pe-`, `start-`, `end-`) خودشان می‌چرخند |
| ارقام | fa → `۱۲۳` · ar → `١٢٣` · en → `123` | یک «حالت ماژول» در `lib/format.ts` که با `setNumberLocale` عوض می‌شود؛ صدها محل فراخوانی `formatRials`/`formatNumber` دست‌نخورده ماندند |
| واحد پول | `ریال` / `ريال` / `IRR` — و `تومان` / `تومان` / `Toman` | `rialUnit()` و `tomanUnit()` |
| نشانه‌ی درصد | `٪` در فارسی و عربی، `%` در انگلیسی | `percentSign()` و `percentText()` |
| تاریخ | همیشه **شمسی** در هر سه زبان | دوره‌ی مالی، سررسید چک و سند حسابداری در ایران شمسی است؛ ترجمه‌ی زبان، تقویم کسب‌وکار را عوض نمی‌کند |
| ذخیره‌ی انتخاب | تنظیم `appearance.language` در پایگاه داده + `localStorage` | تنظیم پایگاه داده روی همه‌ی اجراهای همان نصب اعمال می‌شود؛ `localStorage` فقط پیش از ورود به سیستم به کار می‌آید |

## ۲. ساختار فایل‌ها

```
apps/desktop-ui/src/lib/i18n/
  fa.ts       دیکشنری فارسی — مرجع کلیدها و نوع‌ها
  en.ts       انگلیسی (Dictionary — کامل بودنش را TypeScript تضمین می‌کند)
  ar.ts       عربی
  index.tsx   I18nProvider · useI18n · translate · LOCALES · directionOf
```

## ۳. استفاده در یک صفحه

```tsx
import { useI18n } from '../lib/i18n'

export function MyPage() {
  const { t, locale, dir } = useI18n()
  return <h1>{t('page.products')}</h1>
}
```

متغیرها با `{name}` نوشته می‌شوند:

```tsx
t('alert.overdueChecks', { count: formatCount(3) })
```

## ۵. وضعیت پوشش

**همه‌ی صفحه‌ها و اجزای رابط کاربری سه‌زبانه‌اند** — پوسته (منوی کناری، نوار
بالا با انتخاب‌گر زبان، پالت فرمان، دکمه‌ی شناور، اعلان‌ها، جستجوی سراسری)،
داشبورد، نوار فیلتر، اجزای مشترک، و هر ۲۸ صفحه: کالاها و فرم کالا و قیمت
کالاها · چک‌ها (هر ۱۲ وضعیت) · فاکتورها و فرم فاکتور · اشخاص و فرم شخص ·
گزارشات و گزارش‌ساز · خزانه، حساب‌های خزانه و سند دریافت/پرداخت · اسناد
حسابداری، سند یک‌سطری و کدینگ · انبار پیشرفته، انبارگردانی و انتقال ·
پیش‌فاکتور و سفارش خرید · برگشت از فروش و خرید · تولید و فرمول تولید ·
ورود و خروج اطلاعات · قالب‌های چاپ · اتصالات و افزونه‌ها · مرکز تنظیمات.

تست `ز۱۴` نگهبان این وضعیت است: هر متن فارسیِ سخت‌کدشده‌ی تازه در این
فایل‌ها، تست را قرمز می‌کند.

**عمداً فارسی می‌ماند:** خروجی چاپ فاکتور رسمی و سند حسابداری. صورتحساب
رسمی در ایران باید فارسی باشد؛ تغییر زبان رابط، سند قانونی را دوزبانه
نمی‌کند. همچنین برچسب‌هایی که از هسته‌ی مالی می‌آیند (مثل عنوان گذار چک یا
نوع شخص) در انگلیسی و عربی از روی **شناسه‌ی ساختاری** ترجمه می‌شوند، نه از
روی متن فارسی.

## ۶. افزودن یک زبان تازه

۱. فایل `lib/i18n/xx.ts` با `Dictionary` بساز — TypeScript کلید جامانده را
   خطا می‌دهد.
۲. در `index.tsx` به `LOCALES` و `DICTIONARIES` اضافه کن (با `dir` درست).
۳. در `lib/format.ts` به `INTL_TAG` و `CURRENCY_WORDS` اضافه کن.
۴. در `settings.rs` گزینه‌ی تازه را به `appearance.language` اضافه کن.
۵. تست‌های `__tests__/i18n.test.tsx` خودشان زبان تازه را می‌سنجند.
