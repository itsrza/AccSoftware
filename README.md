# Novin Pardaz Next-Generation Accounting Platform

Version: **1.7.0**

Tauri 2 + React + TypeScript + Rust + SQLite.

This release completes the Reports + Dashboard phase using real persisted application data. Dashboard figures are no longer hard-coded.


## v1.4.0
Advanced inventory and warehouse management is enabled. Inventory operations now include valuation method selection, reservations, batch/serial tracking, stock counting, variance posting, and in-transit transfers.


## v1.7.0
Advanced Settings + Import/Export Data + Print Templates. Demo content is seeded as connected training data. Development builds expose a temporary header action to remove demo business data; this control must be removed from commercial builds.
